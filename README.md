# Exam Prep AI Backend

Backend principal de Exam Prep AI construido con FastAPI, Supabase, Celery y arquitectura moderna preparada para IA escalable.

---

# 🚀 Tecnologías

## Core Backend
- Python 3.12
- FastAPI
- SQLAlchemy
- Alembic
- PostgreSQL

## IA
- OpenAI API
- Embeddings
- RAG Pipeline
- Vector Search

## Async & Workers
- Celery
- Redis

## Auth
- Supabase Auth
- JWT Validation

## Infraestructura
- Docker
- Docker Compose
